## Week 3: Variables, Data Types, Expressions and Input/Output

### Objectives
- Declare and initialize Java variables.
- Use appropriate primitive and reference data types.
- Perform arithmetic calculations.
- Read keyboard input using the Scanner class.
- Display formatted output.
- Compile, test and submit Java programs using GitHub.

### Programs

1. `week03/SimpleCalculator.java`
   - Performs arithmetic calculations on two numbers.
   - Calculates the sum, difference, product and quotient.

2. `week03/AverageCalculator.java`
   - Accepts a student's name and three scores.
   - Calculates the total and average score.
   - Displays the student's result.

3. `week03/ItemCost.java`
   - Accepts an item name, quantity and unit price.
   - Calculates the total cost of the items.
   - Displays the purchase summary.

### How to Run

Open a terminal in the `week03` directory.

Compile and run the calculator:

`javac SimpleCalculator.java`

`java SimpleCalculator`

Compile and run the average calculator:

`javac AverageCalculator.java`

`java AverageCalculator`

Compile and run the item-cost program:

`javac ItemCost.java`

`java ItemCost`

### Testing
Test each program with different valid inputs and verify that the results match the expected calculations.

For the calculator, test ordinary numbers and division by zero.

For the average calculator, test different scores and ensure that scores are within the valid range of 0 to 100.

For the item-cost program, test different quantities and unit prices.

### Learning Outcome
I learnt how to use variables, data types, arithmetic expressions and keyboard input in Java. I also practised displaying formatted output, testing programs, debugging errors and organizing my source code for submission through GitHub.

## Version Control and Submission

The project is managed using Git and GitHub.

The steps followed are:
1. Write and save the Java source code in Visual Studio Code.
2. Compile and run the programs to check for errors.
3. Update this README file with the practical details.
4. Review the changes in GitHub Desktop.
5. Commit the changes to the repository.
6. Push the changes to GitHub.
7. Verify that the source files and README are visible online.
8. Copy the actual GitHub repository URL for submission.
